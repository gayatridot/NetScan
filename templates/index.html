03 / PURPOSE BUILT

Clarity in a
connected world.

NETSCAN is a Python-based IP and network information tool designed to demonstrate fundamental networking concepts through an interactive web interface.

It uses Python’s socket and ipaddress modules to retrieve server-side network information and analyze addresses. It never probes a target or discovers devices.
